About ThreatLens

Our Mission

ThreatLens aims to provide advanced threat detection capabilities through machine learning, helping security researchers and organizations identify potential data leaks and security threats across the web. Our system leverages cutting-edge ML algorithms to analyze and classify websites with high accuracy.

Key Features

🤖

Multiple ML Models

Choose from various machine learning models including Naive Bayes, XGBoost, CatBoost, Random Forest, and Gradient Boosting for accurate classification.

⚡

Fast Processing

Quick analysis and classification of websites with efficient keyword extraction and model inference capabilities.

📊

Batch Processing

Upload CSV or Excel files to analyze multiple URLs at once, perfect for large-scale threat intelligence operations.

🔐

Tor Support

Built-in Tor proxy support for analyzing .onion sites and maintaining anonymity during threat intelligence gathering.

🎯

Keyword Extraction

Advanced NLP-based keyword extraction using NLTK to identify the most relevant terms from analyzed websites.

📈

High Accuracy

Models trained using SMOTE (Synthetic Minority Over-sampling Technique) for balanced and accurate predictions.

🛡️

Threat Prediction

Advanced predictive analytics to assess threat likelihood based on content patterns, keywords, and behavioral indicators, enabling proactive security monitoring and risk prioritization.

📱

Telegram Alerts

Real-time notifications via Telegram for threat detections and classifications, keeping security teams instantly informed of potential risks and enabling rapid response.

How Classification Works

1

Web Scraping

The system fetches the website content using HTTP requests (with optional Tor proxy) and extracts clean text from the HTML using BeautifulSoup.

2

Keyword Extraction

Using NLTK and natural language processing techniques, the system extracts the top 10 most relevant keywords, filtering out common stop words.

3

Vectorization

Keywords are transformed into numerical features using pre-trained TF-IDF vectorizers specific to each machine learning model.

4

Classification

The selected ML model analyzes the vectorized features and predicts whether the site is related to "Leaks" or "Others" category.

5

Threat Prediction

Beyond classification, the system generates a risk score and threat probability based on content analysis, keyword patterns, and historical indicators. This enables security teams to prioritize responses and proactively monitor high-risk targets.

Available Models

  • 🔹 Naive Bayes: Probabilistic classifier based on Bayes' theorem
  • 🔹 XGBoost: Gradient boosting framework optimized for speed and performance
  • 🔹 CatBoost: Gradient boosting library with categorical feature support
  • 🔹 Random Forest: Ensemble learning method using multiple decision trees
  • 🔹 Gradient Boosting: Traditional gradient boosting for classification
